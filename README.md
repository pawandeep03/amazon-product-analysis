# amazon-product-analysis
Power BI project analyzing Amazon product performance, product ratings, discount and pricing insights.
📊 Amazon Sales Dashboard — Power BI

This project analyzes Amazon product data to uncover insights into sales, pricing, and ratings. Built in Power BI, the dashboard visualizes key metrics to support business decisions and identify high-performing products.

🔍 Key Insights

.Top 10 rated and best-selling products

.Relationship between price and customer rating

.Category-wise sales distribution

.Discount vs. actual price comparison

🧰 Tools Used

Power BI

Excel (for data cleaning)

DAX for calculated measures
